# Non-Invasive Electric Field-Based Neuromodulation Device for Alzheimer's Therapy  

This repository contains **regulatory documentation samples** and **technical details** for a prototype developed at IIT Guwahati.  
The project focuses on using non-invasive electric fields for **Alzheimer’s therapy**.  

## Project Highlights
- **TRL-4 prototype** developed with custom PCB and electrode design.  
- Designed in compliance with **IEC 60601 (safety)** and **ISO 14971 (risk management)**.  
- Documentation aligned with **FDA 510(k)**, **EU MDR Class IIa**, and **CDSCO investigational device** requirements.  

## Repository Structure
- `Technical_Dossier.md` – Device description, intended use, regulatory pathways.  
- `Risk_Management_File_ISO14971.md` – Hazard analysis and mitigation plan.  
- `IEC60601_Test_Report_Sample.md` – Example safety and EMC test reporting.  
- `Design_History_File.md` – Requirements, design outputs, verification traceability.  

## Disclaimer
These documents are **educational samples** created for demonstrating knowledge of regulatory affairs and are not intended for official submission to any authority.
