# Design History File (DHF) – Neuromodulation Device  

- **User Needs:** Non-invasive, safe, effective cognitive therapy.  
- **Design Inputs:** IEC 60601 compliance, ISO 14971 risk control, TRL-4 prototype.

- **Verification:** Bench testing of circuits.  
- **Validation:** Pending clinical usability testing.
