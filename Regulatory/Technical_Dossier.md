# Technical Dossier – Neuromodulation Device for Alzheimer's Therapy  

## Device Description  
- Non-invasive electric field-based neurostimulation device for Alzheimer’s treatment.  
- Intended Use: Cognitive improvement and slowing disease progression.  

## Design Overview  
- Block Diagram of system (Electrodes + PCB + Power Source + Control Unit).  
- Safety features integrated per IEC 60601.  

## Regulatory Pathways  
- US FDA: Class II (likely 510(k)).  
- EU MDR: Class IIa.  
- CDSCO: Investigational Medical Device – Clinical Trial Approval required.
